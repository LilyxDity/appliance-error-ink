The funniest honest error message a printer could show:

> ERROR: Ink low. The ink is not low. It has never been low. I am programmed to say this every 200 pages.

Every printer owner has been told the ink is low when the cartridge is still
half full — and has bought a new one anyway, because the machine said so.
The laugh comes from the truth of the fault, not a pun bolted on — the
printer is not malfunctioning, it is confessing that the warning itself is
the fault. The flat error-code opening and the deadpan admission make it
read like a real display message, as if the machine wrote it without
meaning to be funny.

## Run it

```sh
node main.ts
```

This writes the single line (103 characters, one line, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
